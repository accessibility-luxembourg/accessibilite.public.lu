---
title: Image-test
---

Image servant dans un test, captcha ou une image servant de test dans un quiz ou un jeu. 

Exemple : une série d’images présente un détail issu de tableaux célèbres ; il faut reconnaître le titre et le peintre de chaque tableau. Dans cette situation, il n’est pas possible de donner un nom accessible pertinent (par exemple le nom du tableau et/ou du peintre) sans rendre le test inutilisable. Le nom accessible doit alors se contenter de donner la possibilité d’identifier l’image, par exemple &laquo;&nbsp;image 1 du test&nbsp;&raquo;.
