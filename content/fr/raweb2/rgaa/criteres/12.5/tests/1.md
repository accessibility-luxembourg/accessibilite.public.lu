---
title: Dans chaque ensemble de pages, les mécanismes d'aide se présententils toujours dans le même ordre relatif dans le code source (hors cas particuliers) ?
---

1. Choisir une page de l’échantillon appartenant au même ensemble que la page en cours d’audit.
2. Comparer le code source (généré côté client) des deux pages et vérifier que les mécanismes d'aide se présentent toujours dans le même ordre relatif dans la structure.
3. Si c’est le cas, **le critère est validé.**
