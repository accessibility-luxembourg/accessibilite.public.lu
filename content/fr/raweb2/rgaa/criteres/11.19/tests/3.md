title: Pour chaque champ qui possède une [instruction](#instruction)  visuellement accolée au champ, l'instruction vérifie-t-elle une de ces conditions ? 
steps:
- L'instruction est intégrée dans le [nom accessible](#nom-accessible-de-champ-de-formulaire) du champ.
- L'instruction est intégrée dans la [description accessible](#description-accessible) du champ.
- L'instruction est intégrée dans le [nom accessible du regroupement](#nom-accessible-de-regroupement) auquel appartient le champ.
---

1. Retrouver dans le document les instructions visuellement accolées à leur champ.
2. Pour chaque instruction identifiée au {% crit 11.16 %}, vérifier que :
	- soit l’instruction est intégrée dans le nom accessible du champ ;
	- soit l’instruction est intégrée dans la description accessible du champ ;
	- soit l’instruction est intégrée dans le nom accessible du regroupement auquel appartient le champ.
3. Si c’est le cas, **le test est validé**.
