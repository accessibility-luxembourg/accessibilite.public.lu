---
title: Pour chaque application web qui permet une communication orale et écrite en temps réel, les messages de chaque source sont regroupés en blocs de texte présentés par ordre chronologique de création ou de modification ?
---

1. Activer l’application web sur deux terminaux et les connecter à une même session
2. Saisir du texte depuis le premier terminal et saisir du texte depuis le second terminal.
3. Vérifier que les blocs de texte de chacune des sources : 
	- sont présentés séparément (ils sont distincts dans la présentaion, des blocs de texte différenciés sont perceptibles) ;
	- par ordre chronologique.
4. Modifier un caractère dans un bloc existant et vérifier que le bloc est correctement repositionné dans l'ordre chronologique parmi les autres blocs, selon l'heure de la modification.
5. Si c'est le cas, **le test est validé.**
