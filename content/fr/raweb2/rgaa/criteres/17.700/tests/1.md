---
title: Pour chaque application web qui permet une communication orale et écrite en temps réel, l'interface de saisie de texte en temps réel respecte-t-elle ces conditions ?
steps:
- Il est possible d'ajouter du texte pendant une édition en cours.
- Il est possible d'effacer du texte, sans limitation, dans une édition en cours.
- La correction automatique (correction orthographique, reconnaissance vocale) est disponible si elle l'est pour la saisie de texte générale sur le terminal.
---

1. Activer l'application web et établir une communication écrite en temps réel entre deux terminaux.
2. Saisir plusieurs lignes de texte depuis le premier terminal (en créant des sauts de ligne dans le message en cours, sans l'envoyer).
3. Depuis la zone qui contient le texte en cours d'édition, vérifier qu'il est possible d'ajouter des caractères sans être limité (par exemple, il est possible d'ajouter des caractères au début du texte ou d'insérer des caractères entre le texte déjà présent).
4. Vérifier que le texte ajouté apparaît également sur le second terminal de manière synchronisée.
5. Depuis la zone qui contient le texte en cours d'édition, vérifier qu'il est possible d'effacer des caractères sans être limité (par exemple, la touche retour arrière n'est pas bloquée par un saut de ligne ou un autre délimiteur).
6. Vérifier que le texte effacé disparaît également sur le second terminal de manière synchronisée.
7. Vérifier que les mécanismes de correction automatique disponibles sur le terminal (correction orthographique, auto-complétion) fonctionnent dans l'interface de saisie de texte en temps réel.
8. Si c'est le cas, le test est validé.
