1. Choisir une page de l’échantillon appartenant au même ensemble que la page en cours d’audit.
2. Comparer visuellement les deux pages et vérifier que le moteur de recherche se présente toujours dans le même ordre relatif dans la présentation (par exemple, il est toujours avant la navigation principale).
3. Comparer le code source (généré côté client) des deux pages et vérifier que le moteur de recherche se présente toujours dans le même ordre relatif dans la structure.
4. Si c’est le cas, **le test est validé**.
