title: Dans chaque ensemble de pages, la fonctionnalité vers [la page « plan du site »](#page-plan-du-site) respecte-t-elle ces conditions ?
steps:
  - La fonctionnalité se présente toujours dans le même ordre relatif dans la présentation.
  - La fonctionnalité se présente toujours dans le même ordre relatif dans le code source.
---

1. Choisir une page de l’échantillon appartenant au même ensemble que la page en cours d’audit.
2. Comparer visuellement les deux pages et vérifier que le moyen d’accès au plan du site se présente toujours dans le même ordre relatif dans la présentation (par exemple, elle est toujours dans le pied de page avant les coordonnées).
3. Comparer le code source (généré côté client) des deux pages et vérifier que le moyen d’accès au plan du site se présente toujours dans le même ordre relatif dans la structure.
4. Si c’est le cas, **le test est validé**.
