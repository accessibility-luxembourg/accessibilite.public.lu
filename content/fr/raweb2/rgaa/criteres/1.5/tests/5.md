---
title: Chaque image bitmap (balise `<canvas>`), porteuse d’information, qui nécessite une description détaillée, vérifie-t-elle une de ces conditions ?
steps:
  - Il existe un [nom accessible](#nom-accessible-d-image) contenant la référence à une description détaillée adjacente à l’image.
  - Il existe un [lien ou un bouton adjacent](#lien-ou-bouton-adjacent) permettant d’accéder à la description détaillée.
  - Il existe un contenu textuel entre `<canvas>` et `</canvas>` faisant référence à une description détaillée adjacente à l’image.
  - Il existe un contenu textuel entre `<canvas>` et `</canvas>` faisant office de description détaillée.
---

1. Retrouver dans le document les éléments `<canvas>` porteurs d’information qui nécessitent une description détaillée.
2. Pour chaque élément `<canvas>`, vérifier qu’il existe :
	- soit un nom accessible contenant la référence à une description détaillée adjacente à l’image ;
	- soit un lien ou un bouton adjacent permettant d’accéder à la description détaillée ;
	- soit un contenu textuel entre `<canvas>` et `</canvas>` faisant référence à une description détaillée adjacente à l’image ;
	- soit un contenu textuel entre `<canvas>` et `</canvas>` faisant office de description détaillée.
3. Si c’est le cas, **le test est validé**.
