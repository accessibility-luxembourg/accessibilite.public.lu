---
title: Pour chaque application web qui permet une communication orale et écrite en temps réel, la fonctionnalité de saisie du texte en temps réel autorise-t-elle toutes les méthodes de saisie de texte disponibles sur le terminal ?
---

1. Activer l'application web et connecter deux terminaux à une même session.
2. Tester l'une après l'autre chaque méthode de saisie de texte disponible sur le terminal, par exemple :
	- clavier physique ;
	- clavier virtuel à l'écran ;
	- dictée vocale ;
	- clavier alternatif (clavier en braille, clavier adapté, etc.) ;
	- clavier externe connecté par câble, Wi-Fi ou Bluetooth.
3. Pour chaque méthode de saisie, vérifier que le texte saisi apparaît correctement sur le second terminal.
4. Si c'est le cas, **le critère est validé.**
