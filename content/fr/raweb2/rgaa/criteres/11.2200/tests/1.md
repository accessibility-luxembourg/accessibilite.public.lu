---
title: Pour chaque champ message d'erreur visuellement accolé au champ, le message respecte-t-il une de ces conditions ? 
steps:
- Le message est intégré dans le [nom accessible](#nom-accessible-de-champ-de-formulaire) du champ ;
- Le message est intégré dans la [description accessible](#description-accessible) du champ ;
- Le message est intégré dans la [légende du groupement](#legende) auquel appartient le champ.
---

1. Retrouver dans le document les messages d'erreurs visuellement accolée au champ.
2. Pour chaque message, vérifier que :
	- soit le message est intégré dans le nom accessible du champ ;
	- soit le message est intégré dans la description accessible du champ ;
	- soit le message est intégré dans la légende du groupement auquel appartient le champ.
3. Si c’est le cas, **le critère est validé**.
