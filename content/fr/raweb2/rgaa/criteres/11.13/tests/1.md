---
title: Chaque bouton de type image (`<input type="image"/>`) a-t-il un nom accessible ?
---

1. Retrouver dans les boutons de type image (`<input type="image"/>`).
2. Pour chaque bouton de type image, vérifier que le bouton de formulaire dispose d'un nom accessible fourni :
	- par le contenu lié de l'attribut WAI-ARIA `aria-labelledby` ;
	- sinon par le contenu de l'attribut WAI-ARIA `aria-label` ;
	- sinon par le contenu de l'attribut `alt` ;
	- sinon par le contenu de l'attribut `title`.
3. Si c’est le cas, **le critère est validé**.
