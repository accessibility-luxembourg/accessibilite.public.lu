---
title: Pour chaque instruction donnée dans un [média temporel](#media-temporel-type-son-video-et-synchronise) qui repose sur une caractéristique sensorielle, l'instruction est accompagnée d'une méthode alternative qui ne repose pas uniquement sur une caractéristique sensorielle. Cette règle est-elle respectée ?
---

1. Retrouver dans le document les médias temporels qui contiennent des instructions reposant sur une caractéristique sensorielle (la forme, la couleur, la taille, l’emplacement visuel, l’orientation ou encore le son). Par exemple : 
	- une instruction qui demande d'&laquo;&nbsp;Activer le bouton rond&nbsp;&raquo; ;
	- une consigne d'examen qui indique &laquo;&nbsp;Vous pourrez changer de page lorsque vous entendrez le bip sonore&nbsp;&raquo;.
2. Pour chaque instruction, vérifier que : 
	- l'instruction peut être comprise et suivie sans la nécessité de percevoir la caractéristique sensorielle, grâce à la présence d'une méthode alternative (par exemple, description de l'élément concerné par la voix-off) ;
	- la méthode alternative ne repose pas uniquement sur une caractéristique sensorielle. 
3. Si c’est le cas, **le test est validé**.
