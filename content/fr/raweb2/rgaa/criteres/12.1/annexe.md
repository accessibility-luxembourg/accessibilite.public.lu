#### Cas particuliers

Le critère ne s'applique pas :

- lorsque le site web est constitué d’une seule page ;
- lorsque la page est le résultat ou une partie d’un processus (un processus de paiement ou de prise de commande, par exemple).

#### Notes techniques 

Dans la dernière condition du test, l'appréciation d’un nombre très limité de pages devrait être réservée aux sites web de quelques pages. Les WCAG ne fixent pas de seuil maximal de pages, mais citent des cas de sites web de 3, 4 ou 5 pages.
