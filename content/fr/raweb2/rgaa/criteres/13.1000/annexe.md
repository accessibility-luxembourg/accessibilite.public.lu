#### Notes techniques

##### Note 1

Pour une authentification qui repose sur un appareil tiers (authentification à double facteur par exemple), des dispositions doivent être en place pour que le code soit disponible dans le presse-papiers de l'utilisateur. La vérification du critère portera uniquement sur la possibilité de coller le contenu du presse-papiers dans le champ prévu à cet effet pour la demande d'authentification. Évaluer si le contenu peut être transféré ou non de manière simple depuis l'appareil tiers vers l'appareil principal est hors du périmètre de ce critère.

##### Note 2

Ce critère concerne les différentes étapes des processus d'authentification à un compte existant. Le critère n'évalue pas les étapes de création d'un nom d'utilisateur ou d'initialisation d'un compte. Par contre, les étapes de récupération d'e-mail et de mot de passe font partie du processus d'authentification.
