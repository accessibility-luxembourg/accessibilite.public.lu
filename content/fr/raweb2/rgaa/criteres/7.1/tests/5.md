---
title: Chaque composant d'interface ayant une [description accessible](#description-accessible), cette description est-elle pertinente ?
---

1. Retrouver dans le document tous les composants d’interface ayant une description accessible (exceptés les liens et les champs de formulaires, évalués dans des thématiques dédiées).
2. Pour chaque composant, vérifier que la description accessible est pertinente.
3. Sinon, vérifier la présence dans la page d'un [composant alternatif](#contenu-alternatif) au composant d’interface, qui soit conforme et qui permette d’accéder aux mêmes information et fonctionnalités.
4. Si c’est le cas, **le test est validé.**
