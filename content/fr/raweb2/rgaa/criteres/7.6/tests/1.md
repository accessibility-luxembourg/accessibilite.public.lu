---
title: Chaque message de statut respecte-t-il une de ces conditions ?
steps:
 - L'élément est contenu dans une balise possédant l'attribut WAI-ARIA `role="status"`.
 - L'élément est contenu dans une balise possédant l'attribut WAI-ARIA `role="alert"`.
 - L'élément est contenu dans une balise possédant l'attribut WAI-ARIA `role="log"`.
 - L'élément est contenu dans une balise possédant l'attribut WAI-ARIA `role="progressbar"`.
 - L'élément est contenu dans une balise possédant l'attribut WAI-ARIA `aria-live="polite"`.
 - L'élément est contenu dans une balise possédant l'attribut WAI-ARIA `aria-live="assertive"`.
---

1. Retrouver dans le document les messages qui valent pour message de statut.
2. Pour chacun de ces messages, déterminer la nature de l’information dont est porteur le message, vérifier que l’élément qui contient le message utilise :
	- soit l'attribut WAI-ARIA `role="status"` (de préférence pour les messages informant de la progression d'un processus, de la réussite, du résultat d’une action ou bien de l’état d’une application) ; 
	- soit l'attribut WAI-ARIA `role="alert"` (de préférence pour les messages présentant une suggestion ou l'existence d'une erreur) ; 
	- soit l'attribut WAI-ARIA `role="log"` (de préférence pour les messages informant de la progression d'un processus) ;  
	- soit l'attribut WAI-ARIA `role="progressbar"` (de préférence pour les messages informant de la progression d'un processus) ;
	- soit l'attribut WAI-ARIA `aria-live="polite"` ;
	- soit l'attribut WAI-ARIA `aria-live="assertive"`.
3. Si c’est le cas, **le test est validé**.
