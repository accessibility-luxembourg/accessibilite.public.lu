---
title: Chaque image (balise `<img>` ou balise possédant l’attribut WAI-ARIA `role="img"`) porteuse d’information a-t-elle un nom accessible ?
---

1. Retrouver dans le document les images structurées au moyen d’un élément `<img>` ou d’un élément possédant l’attribut WAI-ARIA `role="img"`.
2. Pour chaque image, déterminer si l’image est porteuse d’information.
3. Dans le cas où il s’agit d’un élément `<img>`, vérifier que l'image dispose d'un nom accessible fourni :
	- par le contenu lié de l'attribut WAI-ARIA `aria-labelledby` ;
	- sinon par le contenu de l’attribut WAI-ARIA `aria-label` ;
	- sinon par le contenu de l’attribut `alt` ;
	- sinon par le contenu de l’attribut `title`.
4. Dans le cas où il s’agit d’un élément possédant l’attribut WAI-ARIA `role="img"`, vérifier que l’image dispose d'un nom accessible fourni :
	- par le contenu lié de l’attribut WAI-ARIA `aria-labelledby` ;
	- sinon par le contenu de l’attribut WAI-ARIA `aria-label`.
5. Si c'est le cas, **le test est validé**.
