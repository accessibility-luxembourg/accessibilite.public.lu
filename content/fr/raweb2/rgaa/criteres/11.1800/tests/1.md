---
title: Pour chaque champ dont l’indication du caractère obligatoire ou facultatif est visuellement accolée au champ, l’indication respecte-t-elle une de ces conditions ? 
steps:
- L’indication est intégrée dans le [nom accessible](#nom-accessible-de-champ-de-formulaire) du champ ;
- L’indication est intégrée dans la [description accessible](#description-accessible) du champ ;
- L’indication est intégrée dans la [légende du groupement](#legende) auquel appartient le champ.
---

1. Retrouver dans le document les champs de formulaire obligatoires dont l’indication du caractère obligatoire ou facultatif est visuellement accolée au champ.
2. Pour chaque indication du caractère obligatoire ou facultatif, vérifier que :
	- soit l’indication est intégrée dans le nom accessible du champ ;
	- soit l’indication est intégrée dans la description accessible ;
	- soit l’indication est intégrée dans la légende du groupement auquel appartient le champ.
3. Si c’est le cas, **le critère est validé**.
