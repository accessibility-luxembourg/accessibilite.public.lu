---
title: Pour chaque application web qui permet une communication orale et écrite en temps réel, les messages respectent-ils ces conditions ?
steps:
- La présentation permet d'identifier la source de chaque message ;
- Les messages de sources différentes sont séparés dans la présentation ;
- L'identification de la source de chaque message est accessible aux technologies d'assistance.
---

1. Activer l’application web et la fonctionnalité de communication écrite en temps réel de l’application sur deux terminaux et les connecter à une même session.
2. Envoyer un message écrit depuis les deux terminaux pour obtenir des messages de sources différentes.
3. Vérifier :
	- que les messages de sources différentes sont visuellement séparés (par exemple, par une mise en forme, une couleur, un positionnement ou une annotation qui les distingue) ;
	- que la source de chaque message est identifiable visuellement (par exemple, par le nom ou l'identifiant de l'expéditeur affiché à proximité du message, un identifiant unique comme « Participant 1 » est suffisant, une identité réelle n'est pas requise) ;
	- que l'identification de la source de chaque message est accessible aux technologies d'assistance (une information textuelle est disponible pour apporter cette information).
4. Si c’est le cas, le test est validé.
