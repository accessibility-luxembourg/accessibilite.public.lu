---
title: Pour chaque lien ayant un intitulé visible, le nom accessible du lien contient-il au moins l’intitulé visible (hors cas particuliers) ?
---

1. Retrouver dans le document les liens autres que SVG avec un intitulé visible et un nom accessible.
2. Pour chaque lien, vérifier que le nom accessible déterminé au {% crit 6.1 %} contient au moins l’intitulé visible.
3. Si c’est le cas pour chaque lien, le test est validé pour les liens autres que SVG.
4. Retrouver dans le document les liens SVG avec un intitulé visible et un nom accessible.
5. Pour chaque lien SVG, vérifier que le nom accessible déterminé au {% crit 6.1 %} contient au moins l’intitulé visible.
6. Si c’est le cas pour chaque lien SVG, le test est validé pour les liens SVG.
7. Si le test est validé à la fois pour les liens non SVG et pour les liens SVG, **le critère est globalement validé**.
