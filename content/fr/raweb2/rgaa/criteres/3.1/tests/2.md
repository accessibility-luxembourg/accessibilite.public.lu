---
title: Pour chaque indication de couleur donnée par un texte, l’information est accompagnée d'une alternative visible qui ne repose pas sur la couleur. Cette règle est-elle respectée ?
---

1. Retrouver dans le document les informations données par la couleur dans un texte (par exemple, la légende d'un code couleur).
2. Pour chacune de ces informations, vérifier que l'information est aussi donnée par un moyen visible qui ne repose pas sur la couleur (icône, effet graphique de forme ou de position, un effet typographique, texte visible adjacent…).
3. Si c’est le cas, **le test est validé**.
