---
title: Pour chaque application web de télécommunication, les informations d'identification de l’interlocuteur qui initie un appel respectent-elle ces conditions ?
steps:
- Toutes les informations d'identification de l’interlocuteur sont présentées sous forme de texte ;
- Toutes les informations d'identification de l’interlocuteur sont accessibles aux technologies d’assistance.
---

1. Activer l’application web depuis un terminal.
2. Depuis un second terminal, lancer un appel vers le premier terminal.
3. Lorsque l’appel entrant apparaît, vérifier :
	- que les informations d'identification de l’interlocuteur sont disponibles visuellement sous la forme d’un texte dont la nature est compréhensible (par exemple, le nom et le numéro de téléphone) ;
	- que ces informations sont compatibles avec les technologies d’assistance : par exemple, par l’utilisation d’un message de statut pertinent.
4. Si c’est le cas, le test est validé.
