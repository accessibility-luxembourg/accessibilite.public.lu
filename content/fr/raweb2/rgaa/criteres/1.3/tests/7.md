---

1. Retrouver dans le document les éléments `<canvas>` pourvus d’un contenu alternatif entre les balises `<canvas>` et `</canvas>`.
2. Pour chaque élément, vérifier que le contenu alternatif est correctement restitué par les technologies d’assistance.
3. Si c’est le cas, **le test est validé**.
