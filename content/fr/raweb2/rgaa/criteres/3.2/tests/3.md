---
title: Pour chaque [image véhiculant une information](#image-vehiculant-une-information-donnee-par-la-couleur), l’information  est accompagnée d'une alternative accessible aux technologies d'assistance. Cette règle est-elle respectée ?
---

1. Retrouver dans le document les informations données par la couleur dans une image.
2. Pour chacune de ces informations, vérifier la présence d'un texte visible adjacent, d'un texte visuellement masqué, ou d'un autre complément au niveau du code (`title`, `aria-label`, `aria-current`, etc.).
3. Si c’est le cas, **le test est validé**.
