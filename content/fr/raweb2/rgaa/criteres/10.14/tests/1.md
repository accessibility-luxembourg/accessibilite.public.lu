---
title: Chaque page web vérifie-t-elle ces conditions ? 
steps:
  - La page web ne bloque pas l'application des préférences de l'utilisateur, pour les fonctionnalités d'accessibilité documentées par l'agent utilisateur.
  -  La page ne surcharge pas explicitement les préférences de l'utilisateur, pour les fonctionnalités d'accessibilité documentées par l'agent utilisateur.
---

1. Rechercher le fonctionnalités d'accessibilité documentées par l'agent utilisateur : 
	- dans une documentation dédiée ; 
	- ou depuis la liste des paramètres d'accessibilité personnalisables, directement dans le navigateur.
2. Rechercher dans les styles qui s'appliquent sur la page, l'absence de déclaration bloquantes dans les <em lang="en">media queries</em> liées aux préférences utilisateurs :
	- `prefers-color-scheme` ; 
	- `prefers-contrast` ;
	- `prefers-reduced-motion` ;
	- `forced-colors`.
2. ....
