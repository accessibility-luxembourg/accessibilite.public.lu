---
title: Chaque message d’erreur décrit-il la nature de l'erreur ?
---

1. Retrouver dans le document les messages d’erreur.
2. Pour chaque message d’erreur, vérifier que la description de l'erreur est pertinente, par exemple : 
	-  &laquo;&nbsp;Ce champ est obligatoire&nbsp;&raquo; lorsque le message d'erreur concerne l’absence de saisie d’un champ obligatoire ; 
	- &laquo;&nbsp;Exemple de saisie attendue : nom@domain.com&nbsp;&raquo; lorsque le message d'erreur concerne une erreur relative à un type de données et/ou de format.
3. Si c’est le cas, **le test est validé**.
