---
title: Chaque message d’erreur respecte-t-il une de ces conditions ?
steps:
- Le message d’erreur est visible et permet d’identifier nommément le champ concerné.
- Le message d’erreur est situé à proximité du champ.
---

1. Retrouver dans le document les messages d’erreur (indiquant l’absence de saisie d’un champ obligatoire ou fournissant une instruction ou une indication du type de données et/ou de format obligatoire d’un champ).
2. Pour chaque message d’erreur, vérifier :
	- qu’il est indiqué de manière visible ;
	- qu’il permet d’identifier nommément le champ concerné ou est située à proximité du champ.
3. Si c’est le cas, **le test est validé**.
