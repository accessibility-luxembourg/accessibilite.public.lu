title: Pour chaque tableau de données complexe ayant un résumé, celui-ci est-il pertinent ?
---

1. Retrouver dans le document les résumés de tableaux de données complexes (tels que déterminés par le test 5.1.1 [@@TODO numérotation]).
2. Pour chaque résumé, vérifier que son contenu est pertinent.
3. Si c’est le cas, **le test est validé**.
