---
title: Chaque champ dont la saisie requiert un format ou un type de données particulier respecte-t-il une de ces conditions ? 
steps:
- Une indication du type de données et/ou de format est visible et permet d’identifier nommément le champ concerné avant sa saisie.
- Une indication du type de données et/ou de format est visible et visuellement accolée au champ avant sa saisie.
---

1. Remplir les champs de formulaire avec des valeurs susceptibles de provoquer des erreurs de saisies (entrer une adresse <em lang="en">e-mail</em> mal formée par exemple).
2. Valider le formulaire.
3. Pour chaque champ de formulaire qui possède un contrôle du format ou du type de données, vérifier que cette information : 
	- est indiquée avant la saisie ;
	- est indiquée de manière visible ; 
	- permet d’identifier nommément le champ concerné ou est visuellement accolée au champ. 
4. Si c’est le cas, **le critère est validé**.
