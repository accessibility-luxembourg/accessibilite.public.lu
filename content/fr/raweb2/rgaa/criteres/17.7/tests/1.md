---
title: Pour chaque application web qui permet une communication orale et écrite en temps réel, le délai de transmission de chaque unité de saisie est de 500ms ou moins. Cette règle est-elle respectée ?
---

1. Activer l’application web et la fonctionnalité de communication écrite sur deux terminaux distincts et les connecter à une même session.
2. Saisir du texte sur le premier terminal et observer son apparition sur le second terminal. L’apparition sur le second terminal doit être instantanée (inférieure à une seconde : ce seuil d'observation garantit le respect des 500 ms hors délais réseau, conformément à la norme). Un test par observation simple peut être suffisant pour constater l’apparition instantanée sur le terminal qui reçoit le message écrit. Selon le paramétrage de la fonctionnalité, chaque caractère n'est pas nécessairement envoyé individuellement :
	- lorsque le saisie se fait caractère par caractère, chaque caractère doit apparaître dans ce délai ;
	- si la fonctionnalité implémente une prédiction de mots, le mot désiré est envoyé lorsqu'il est sélectionné ;
	- lorsque la sasie se fait par copier-coller, le bloc de texte collé doit apparaître dans ce délai.
3. Si c’est le cas, le test est validé.
