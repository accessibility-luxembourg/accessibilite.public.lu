###### iOS et Android

1. Repérer dans l’écran les éléments visuels utilisés comme CAPTCHA ([voir la note de glossaire concernant les particularités de restitution](#element-graphique)).
1. Pour chacun, vérifier qu’il existe :
	- soit une autre forme de CAPTCHA non visuelle (par exemple, CAPTCHA sonore) ;
	- soit une autre solution d’accès à la fonctionnalité qui est sécurisée par le CAPTCHA (envoi d’un code sms, envoi d’un e-mail de confirmation, etc.).
1. Repérer dans l’écran les séquences sonores utilisées comme CAPTCHA.
1. Pour chacune, vérifier qu’il existe :
	- soit une autre forme de CAPTCHA non sonore (par exemple, CAPTCHA graphique) ;
	- soit une autre solution d’accès à la fonctionnalité qui est sécurisée par le CAPTCHA (envoi d’un code sms, envoi d’un e-mail de confirmation, etc.).
1. Vérifier que l’autre forme de CAPTCHA ou la solution d’accès alternative est conforme.
1. Si c’est le cas, **le critère est validé**.
