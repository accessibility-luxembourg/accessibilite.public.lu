###### iOS et Android

1. Repérer dans l’écran les médias temporels seulement vidéo ou synchronisés pré-enregistrés qui possèdent une audiodescription.
1. Pour chacun, vérifier que l’audiodescription est pertinente (toutes les informations visuelles importantes sont présentes).
1. Repérer dans l’écran les médias temporels synchronisés pré-enregistrés sans audiodescription mais avec une alternative sous forme de texte.
1.  Pour chacun, vérifier :
	- soit que l'alternative texte contient toutes les informations visuelles importantes ;
	- soit que la transcription textuelle contient toutes les informations visuelles importantes.
1. Si c’est le cas, le critère est validé.
