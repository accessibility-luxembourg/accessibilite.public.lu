---
title: Description accessible
---

Description d'un élément d'interface, exposé aux technologies d'assistance par l'intermédiaire de l'API d'accessibilité du système d'exploitation.

La description accessible vient en complément du nom accessible, elle ne peut jamais s'y substituer. La présence d'une description accessible est facultative, contrairement au nom accessible qui est obligatoire.

Un exemple concret d'exploitation de la description accessible par une technologie d'assistance est la restitution d'un élément d'interface par un lecteur d'écran lorsqu'il reçoit le focus. Pour un bouton de formulaire ayant un nom accessible &laquo;&nbsp;Envoyer&nbsp;&raquo; et une description accessible &laquo;&nbsp;Cette action est irréversible&nbsp;&raquo;, le lecteur d'écran annonce une concaténation de son [nom accessible](#nom-accessible), de sa description et de son [rôle calculé](#role-calcule), par exemple : &laquo;&nbsp;Envoyer, Cette action est irréversible, Bouton&nbsp;&raquo;.
