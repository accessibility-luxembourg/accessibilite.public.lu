---
title: Contexte du lien
---

Le contexte du lien représente les informations supplémentaires (on parle d’informations de contexte) qui peuvent être mises en relation par un programme informatique avec le nom accessible du lien. Les informations de contexte qui permettent de compléter le nom accessible du lien sont les suivantes :

- Le contenu de la phrase dans laquelle le lien texte est présent ;
- Le contenu du paragraphe dans lequel le lien texte est présent ;
- Le contenu de l’item de liste ou le contenu d’un item de liste parent dans lequel le lien texte est présent ;
- Le contenu du titre précédent le lien texte ;
- Le contenu de la ou les cellule(s) d’en-tête de tableau associée(s) à la cellule de donnée dans laquelle le lien texte est présent ;
- Le contenu de la cellule de donnée dans laquelle le lien texte est présent.

Note 1 : l’un des 6 contextes de lien combiné à le nom accessible du lien doit permettre de comprendre la fonction et la destination du lien.

Note 2 : RAAM considère qu’une adresse e-mail de type `xxx@xxx.yyy` est un texte de lien suffisant pour comprendre la fonction du lien et ne requiert pas de signaler plus explicitement l’action.
