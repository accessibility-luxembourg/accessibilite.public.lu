2. Comparer visuellement les deux pages et vérifier que les mécanismes de navigation répétés qui ne sont pas déjà couverts par les tests 12.X à 12.X se présentent dans le même ordre relatif dans la présentation (par exemple, toujours avant la zone de contenu principal).
3. Comparer le code source (généré côté client) des deux pages et vérifier que les mécanismes de navigation répétés se présentent toujours dans le même ordre relatif dans la structure.
4. Si c’est le cas, **le test est validé**.
