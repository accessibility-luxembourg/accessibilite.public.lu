title: Dans chaque ensemble de pages, les liens de chaque mécanisme de navigation répété respectent-ils ces conditions ?
steps:
  - Les liens se présentent toujours dans le même ordre relatif dans la présentation.
  - Les liens se présentent toujours dans le même ordre relatif dans le code source.
---

1. Choisir une page de l’échantillon appartenant au même ensemble que la page en cours d’audit.
2. Comparer visuellement les deux pages et vérifier que, pour chaque mécanisme de navigation répété (par exemple, navigation, barre de menu, fil d'ariane) les liens se présentent toujours dans le même ordre relatif dans la présentation (si des liens sont ajoutés entre les deux pages comparées, mais que l'ordre relatif des liens communs aux deux pages est préservé, il n'y a pas de non conformité).
3. Comparer le code source (généré côté client) des deux pages et vérifier que les liens se présentent toujours dans le même ordre relatif dans la structure.
4. Si c’est le cas, **le test est validé**.

Le critère 12.X [@@todo revoir la numérotation] évalue la cohérence de la position des éléments dans les mécanismes de navigation.
