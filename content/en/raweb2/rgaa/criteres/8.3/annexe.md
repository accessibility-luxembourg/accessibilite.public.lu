#### Cas particuliers

Le critère est non applicable pour :

- les noms propres ;
- les [termes techniques](#termes-techniques) ;
- les passages de texte dont la langue ne peut pas être déterminée ;
- les noms communs de langue étrangère couramment utilisés dans la langue par défaut de la page web ;
- les termes de langue étrangère soumis, via un [champ de formulaire](#champ-de-saisie-de-formulaire) et rappelé dans la page (par exemple comme indication du terme recherché dans le cas d’un moteur de recherche) ;
- les termes ou passages de texte issus d’une langue morte ou imaginaire pour laquelle il n’existe pas d’interprétation vocale.

#### Notes techniques 

Pour les noms communs de langue étrangère couramment utilisés dans la langue principale du document, le critère est applicable, uniquement lorsque l’absence d’indication de langue peut provoquer une incompréhension pour la restitution.
