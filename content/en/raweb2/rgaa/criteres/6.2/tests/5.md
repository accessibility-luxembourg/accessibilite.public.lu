---
title: Dans chaque page web, les [liens identiques](#lien-identique) ayant un nom accessible ont-ils les mêmes fonctions et destinations (hors cas particuliers) ?
---

1. Retrouver dans le document les liens qui ont un nom accessible identique.
2. Pour les liens identiques, vérifier qu’ils mènent tous vers la même destination ou vers un contenu similaire.
3. Sinon, vérifier que le contexte de chacun des liens permet de les distinguer.
4. Si c’est le cas, **le test est validé**.
