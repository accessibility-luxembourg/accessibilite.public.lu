---
title: Pour chaque tableau de données ayant un nom accessible, le nom accessible verifie-t-il ces conditions ?
steps:
- Le nom accessible est pertinent, il permet d’identifier le contenu du tableau de données de manière claire et concise.
- Le nom accessible contient la même information que le titre visible, lorsque le tableau a un titre visible.
---

1. Retrouver dans le document les tableaux de données ayant un nom accessible.
2. Pour chaque tableau, vérifier que le nom accessible est pertinent, il permet d'identifier le contenu du tableau de données de manière claire et concise.
3. Pour chaque tableau de données ayant un titre visible et un nom accessible, vérifier que le nom accessible contient la même information que le titre visible.
4. Si c’est le cas, **le critère est validé**.
