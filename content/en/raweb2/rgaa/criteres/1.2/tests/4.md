---
title: Chaque image vectorielle (balise `<svg>`) porteuse d’information, vérifie-t-elle ces conditions ?
steps:
  - La balise `<svg>` possède un attribut WAI-ARIA `role="img"` ;
  - La balise `<svg>` a un nom accessible.
---

1. Retrouver dans le document les éléments `<svg>`.
2. Pour chaque élément `<svg>`, déterminer si l’image est porteuse d’information.
3. Vérifier :
	- que l’élément `<svg>` est pourvu d’un attribut WAI-ARIA `role="img"` ;
	- et que l’élément `<svg>` dispose d'un nom accessible fourni :
		- par le contenu lié de l'attribut WAI-ARIA `aria-labelledby` ;
		- sinon par le contenu de l’attribut WAI-ARIA `aria-label` ;
		- sinon par le contenu de l’élément `<title>` ;
		- sinon par le contenu de l’élément `<text>`.
4. Si c'est le cas, **le test est validé**.
