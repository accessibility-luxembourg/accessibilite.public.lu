---
title: Chaque champ dont le message d'erreur est visuellement accolé au champ vérifie-t-il une de ces conditions ? 
steps:
- Le message est intégré dans le [nom accessible](#nom-accessible-de-champ-de-formulaire) du champ.
- Le message est intégré dans la [description accessible](#description-accessible) du champ.
- Le message est intégré dans le [nom accessible du regroupement](#nom-accessible-de-regroupement) auquel appartient le champ.
- Le champ dispose de l’attribut `aria-invalid="true"` si le message d'erreur n'apporte pas d'informations complémentaires.
---

1. Retrouver dans le document les messages d'erreurs visuellement accolés à leur champ.
2. Pour chaque message identifié au {% crit 11.17 %} et {% crit 11.18 %}, vérifier que :
	- soit le message est intégré dans le nom accessible du champ ;
	- soit le message est intégré dans la description accessible du champ ;
	- soit le message est intégré dans le nom accessible du regroupement auquel appartient le champ ;
	- soit le champ dispose de l’attribut `aria-invalid="true"` si le message d'erreur n'apporte pas d'informations complémentaire (le message d'erreur ne fait qu'annoncer la présence d'une erreur sans la décrire, par exemple &laquo;&nbsp;Champ en erreur&nbsp;&raquo;).
3. Si c’est le cas, **le test est validé**.
