1. Retrouver dans le document les champs de formulaire obligatoires dont l’indication du caractère obligatoire ou facultatif est visuellement accolée au champ.
2. Pour chaque indication du caractère obligatoire ou facultatif identifiée au {% crit 11.16 %}, vérifier que :
	- soit l’indication est intégrée dans le nom accessible du champ ;
	- soit l’indication est intégrée dans la description accessible ;
	- soit l’indication est intégrée dans le nom accessible du regroupement auquel appartient le champ.
3. Si c’est le cas, **le critère est validé**.
