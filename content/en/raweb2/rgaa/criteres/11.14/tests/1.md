---
title: Pour chaque bouton de type image (`<input type="image"/>`) ayant un nom accessible, ce nom accessible est-il pertinent ?
---

1. Retrouver dans le document les boutons de type image (`<input type="image"/>`) (exceptés ceux utilisés comme CAPTCHA ou comme image-test qui sont évalués au test 11.15.2).
2. Pour chaque bouton de type image, vérifier que le nom accessible déterminé au {% crit 11.13 %} permet de connaître la fonction exacte du champ.
3. Si c’est le cas, **le test est validé**.
