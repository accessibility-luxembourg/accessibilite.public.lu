title: Pour chaque image bouton de type image (`<input type="image"/>`) utilisé comme CAPTCHA ou comme image-test, ayant un nom accessible, ce nom accessible est-il pertinent ? 
---

1. Retrouver dans le document les boutons de type image (`<input type="image"/>`) utilisés comme CAPTCHA ou comme image-test.
2. Pour chaque bouton de type image, vérifier que le nom accessible déterminé au {% crit 11.13 %} permet de connaître la fonction exacte du champ.
3. Si c’est le cas, **le test est validé**.
