---
title: Pour chaque image embarquée (balise `<embed>` avec l’attribut `type="image/…"`) porteuse d’information, ayant un nom accessible, ce nom accessible est-il pertinent (hors cas particuliers) ?
---

1. Retrouver dans le document les balises `<embed>` pourvues de l’attribut `type="image/…"` et d’un nom accessible.
2. Pour chaque balise `<embed>` pourvue de l’attribut `type="image/…"`, vérifier que le nom accessible déterminé au critère {% crit 1.2 %} est pertinent. 
3. Sinon, si l'élément `<embed>` est pourvu d'un [contenu alternatif](#contenu-alternatif), vérifier que ce contenu est pertinent. 
4. Si c’est le cas, **le test est validé**.
