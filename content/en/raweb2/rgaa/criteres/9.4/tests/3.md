---
title: Dans chaque page web, les informations regroupées sous forme de liste de description vérifient-elles ces conditions ?
steps:
- La liste de description utilise les balises `<dl>` et `<dt>/<dd>`.
- Les balises structurant la liste de description sont dépourvues de l'attribut WAI-ARIA `role`.
---

1. Retrouver dans le document les éléments regroupés visuellement sous la forme d’une liste de description.
2. Pour chaque liste, vérifier que la liste est structurée au moyen des éléments `<dl>`, `<dt>` et `<dd>`.
3. Pour chaque balise, vérifier qu'ils sont dépourvus de l'attribut WAI-ARIA `role`.
3. Si c’est le cas, **le test est validé**.
