---
title: Chaque image porteuse d’information accompagnée d’une description détaillée et qui utilise un attribut WAI-ARIA `aria-describedby` respecte-t-elle ces conditions ?
steps:
  - L'attribut WAI-ARIA `aria-describedby` associe la description détaillée.
  - La description détaillée associée est correctement restituée par les technologies d’assistance.
---

1. Retrouver dans le document les images (éléments `<img>`, `<input>` avec l’attribut `type="image"`, `<object>`, `<embed>`, `<svg>`, `<canvas>` ou possédant un attribut WAI-ARIA `role="img"`) porteuses d’information dont la description détaillée utilise un attribut WAI-ARIA `aria-describedby`.
2. Pour chaque image, vérifier  : 
	- que l'attribut WAI-ARIA `aria-describedby` associe la description détaillée ;
	- que le contenu de la description détaillée est correctement restitué par les technologies d’assistance.
3. Si c’est le cas, **le test est validé**.
