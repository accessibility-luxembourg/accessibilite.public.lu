---
title: Chaque [bouton](#bouton-formulaire) de type image (balise `<input>` avec l’attribut `type="image"`) porteur d’information, qui nécessite une description détaillée, vérifie-t-il une de ces conditions ?
steps:
  - Il existe un [nom accessible](#nom-accessible-d-image) contenant la référence à une description détaillée adjacente à l’image.
  - Il existe un [lien ou un bouton adjacent](#lien-ou-bouton-adjacent) permettant d’accéder à la description détaillée.
  - Il existe un attribut WAI-ARIA `aria-describedby` associant un [passage de texte](#passage-de-texte-lie-par-aria-labelledby-ou-aria-describedby) visible et adjacent à l'image, faisant office de description détaillée.
---

1. Retrouver dans le document les éléments `<input>` pourvus de l’attribut `type="image"`, porteurs d’information qui nécessitent une description détaillée.
2. Pour chaque élément `<input>` pourvu de l’attribut `type="image"`, vérifier qu’il existe :
	- soit un nom accessible contenant la référence à une description détaillée adjacente à l’image ;
	- soit un lien ou un bouton adjacent permettant d’accéder à la description détaillée ;
	- soit un attribut WAI-ARIA `aria-describedby` associant un passage de texte visible et adjacent à l'image, faisant office de description détaillée. 
3. Si c’est le cas, **le test est validé**.
