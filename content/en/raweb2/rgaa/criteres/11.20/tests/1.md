---
title: Pour chaque formulaire dont la validation a des conséquences financières ou juridiques, la saisie des données vérifie-t-elle une de ces conditions ?
steps:
  - L’utilisateur peut [modifier ou annuler les données et les actions effectuées](#modifier-ou-annuler-les-donnees-et-les-actions-effectues) sur ces données (si un délai existe, il est défini explicitement dans la page).
  - Un mécanisme contrôle les données saisies et l’utilisateur peut vérifier et corriger les erreurs identifiées avant la validation du formulaire.
  - Un mécanisme permet à l'utilisateur de revoir les données saisies, de les corriger et de confirmer explicitement la validation du formulaire.
---

1. Retrouver dans le document les formulaires dont la validation a des conséquences financières ou juridiques.
2. Pour chaque formulaire, vérifier :
	- soit que l’utilisateur peut modifier ou annuler les données et les actions effectuées sur ces données après la validation du formulaire. Si cette possibilité est limitée dans le temps, le délai est défini explicitement sur la page ;
	- soit qu'un mécanisme contrôle les données saisies et l’utilisateur peut vérifier et corriger les erreurs identifiées avant la validation du formulaire ;
	- soit qu'un mécanisme permet à l'utilisateur de revoir les données saisies, de les corriger et de confirmer explicitement la validation du formulation, par exemple, avec une case à cocher (balise `<input>` de type `checkbox` ou balise ayant un attribut WAI-ARIA `role="checkbox"`) ou une étape supplémentaire (une fenêtre modale de confirmation par exemple).
3. Si c’est le cas, **le test est validé**.
