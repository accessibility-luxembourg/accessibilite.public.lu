---

1. Retrouver dans le document les formulaires dont la validation a des conséquences financières ou juridiques.
2. Pour chaque formulaire, vérifier que l’utilisateur peut :
	- soit modifier ou annuler les données et les actions effectuées sur ces données après la validation du formulaire dans un délai défini explicitement sur la page ;
	- soit vérifier et corriger les données avant la validation du formulaire ;
	- soit disposer d’un mécanisme de confirmation explicite, par exemple, une case à cocher (balise `<input>` de type `checkbox` ou balise ayant un attribut WAI-ARIA `role="checkbox"`) ou une étape supplémentaire (une fenêtre modale de confirmation par exemple).
3. Si c’est le cas, **le test est validé**.
