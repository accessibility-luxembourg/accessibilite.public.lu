---
title: Mécanisme de navigation répété
---

Ensemble de liens ou de fonctionnalités permettant de se déplacer dans le site ou de trouver un contenu ou une fonctionnalité, et qui est présent sur plusieurs pages d'un [ensemble de pages](#ensemble-de-pages).

Cette dénomination rassemble plus d'éléments que les seuls [menu et barre de navigation](#menu-et-barre-de-navigation), qui y sont aussi inclus.

On peut citer : 

- le [menu et barre de navigation](#menu-et-barre-de-navigation) : 
	- un menu de navigation, menu de sous-rubrique, menu contextuel ; 
	- un fil d'ariane ;
	- une liste de navigation d’une liste de résultats (pagination) ;
	- des liens d'évitement ou d'accès rapide. 
- le lien vers le plan du site ;
- les liens du pied de page (s'ils permettent de se déplacer dans le site) ;
- le [moteur de recherche](#moteur-de-recherche-interne-a-un-site-web) ; 
- un sélecteur de langue ;
- un [mécanisme d'aide](#mecanisme-d-aide) lorsqu'il est un lien ou un ensemble de liens groupés, le cas échéant, avec d'autres liens (menu dédié, suite de liens en pied de page par exemple) ;
- tout ensemble de liens ou de fonctionnalités qui est présenté au même endroit dans la présentation sur les pages d'un ensemble de pages, et dont les éléments sont les mêmes d'une page à l'autre.
