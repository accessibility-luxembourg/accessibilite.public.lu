---
title: Élément graphique de test
---

[Élément graphique](#element-graphique) servant dans un test, un CAPTCHA ou un élément graphique servant de test dans un quiz ou un jeu. 

Exemple : une série d’éléments graphiques présente un détail issu de tableaux célèbres, il faut reconnaître le titre et le peintre de chaque tableau. Dans cette situation, il n’est pas possible de donner un nom accessible pertinent (par exemple le nom du tableau et/ou du peintre) sans rendre le test inutilisable. Le nom accessible doit alors se contenter de donner la possibilité d’identifier l’élément graphique, par exemple « image 1 du test ».
