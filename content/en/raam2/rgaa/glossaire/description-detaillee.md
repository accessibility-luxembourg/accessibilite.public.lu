---
title: Description détaillée
---

Contenu associé à un [élément graphique](#element-graphique) en complément de son nom accessible afin de décrire en totalité l’information véhiculée par l’élément. La description détaillée peut être associée à l’image via :

- Une référence à une description détaillée [adjacente à l’image](#adjacente-clairement-identifiable) dans le nom accessible ;
- Un lien ou un bouton adjacent qui permet d’accéder à la description détaillée dans l’écran ou dans un autre écran.

Une description détaillée est utile pour tous les utilisateurs. Une description détaillée qui ne serait pas visible à l’écran et uniquement accessible grâce à un lecteur d’écran ne pourrait pas, dans certaines conditions, être considérée comme une implémentation conforme.
