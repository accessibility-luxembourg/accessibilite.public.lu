#### Cas particuliers

L’objectif de ce critère est de garantir un défilement dans une unique direction pour une lecture facilitée selon le sens de l’écriture.

Le critère ne s'applique pas aux contenus dont l’agencement requiert deux dimensions pour être compris ou utilisés comme :

- Les images, les graphiques ou les vidéos ;
- Les jeux (jeux de plateforme, par exemple) ;
- Les présentations (type diaporama, par exemple) ;
- Les tableaux de données ;
- Les interfaces où il est nécessaire d’avoir un ascenseur horizontal lors de la manipulation de l’interface.

#### Notes techniques

Lorsqu’il est ici question de pixel, il s’agit du [pixel CSS tel que défini par le W3C dans la spécification WCAG2ICT](https://www.w3.org/TR/wcag2ict-22/#applying-css-pixel-to-non-web-documents-and-software). 

Les valeurs de 320px et 256px sont les valeurs normatives issues de la norme EN 301 549, néanmoins, les terminaux mobiles ne permettent pas tous d'atteindre ces valeurs. Lorsque les valeurs cibles ne peuvent pas être atteinte, il est acceptable de réaliser le tests avec les plus petites valeurs atteignables dans le terminal de test et de consigner cette valeur dans le relevé d'audit.
