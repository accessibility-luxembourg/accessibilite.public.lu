###### iOS et Android 

1. Repérer dans l’écran les formulaires dont la validation a des conséquences financières ou juridiques, pour chacun, vérifier : 
    - soit que l’utilisateur peut modifier ou annuler les données et les actions effectuées sur ces données après la validation du formulaire. Si cette possibilité est limitée dans le temps, le délai est défini explicitement dans l’écran ;
    - soit qu’un mécanisme contrôle les données saisies et l’utilisateur peut vérifier et corriger les erreurs identifiées avant la validation du formulaire ;
    - soit qu’un mécanisme permet à l’utilisateur de revoir les données saisies, de les corriger et de confirmer explicitement la validation du formulaire, par exemple, avec une case à cocher ou une étape supplémentaire (une fenêtre modale de confirmation par exemple).
1. Repérer dans l’écran les formulaires qui modifient ou suppriment des données contrôlables par l’utilisateur, pour chacun, vérifier :
    - soit qu’un mécanisme permet de récupérer les données supprimées ou de rétablir les données antérieures à une modification de l’utilisateur ;
    - soit qu’un mécanisme contrôle les données saisies et l’utilisateur peut vérifier et corriger les erreurs identifiées avant la validation du formulaire ;
    - soit qu’un mécanisme permet à l’utilisateur de revoir les données saisies, de les corriger et de confirmer explicitement la validation du formulaire, par exemple, avec une case à cocher ou une étape supplémentaire (une fenêtre modale de confirmation par exemple).
1. Repérer dans l’écran les formulaires qui soumettent des réponses à un test ou à un examen, pour chacun, vérifier :
    - soit que l’utilisateur peut modifier ou annuler les données et les actions effectuées sur ces données après la validation du formulaire. Si cette possibilité est limitée dans le temps, le délai est défini explicitement dans l’écran ;
    - soit qu’un mécanisme contrôle les données saisies et l’utilisateur peut vérifier et corriger les erreurs identifiées avant la validation du formulaire ;
    - soit qu’un mécanisme permet à l’utilisateur de revoir les données saisies, de les corriger et de confirmer explicitement la validation du formulaire, par exemple, avec une case à cocher ou une étape supplémentaire (une fenêtre modale de confirmation par exemple).
1. Si c’est le cas, **le critère est validé**.
